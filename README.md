### 🤖 AI Destekli Chatbot Sistemleri

Gerçek kullanıcı senaryolarını anlayabilen, gerektiğinde backend servislerinden
veri toplayabilen ve doğru aksiyonu seçebilen AI destekli chatbot sistemleri
üzerinde çalışıyorum.

Bu kapsamda:

- LLM tabanlı intent ve karar mekanizmaları
- Tool / function calling
- RAG ve vector search
- Conversation & session yönetimi
- Context optimizasyonu
- Prompt engineering
- AI response evaluation
- Laravel servisleri ile LLM entegrasyonu

gibi konularla ilgileniyorum.

**Stack:** Laravel • Vue.js • MySQL • Qdrant • Docker • OpenAI API
