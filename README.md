## 🔬 Şu An Üzerinde Çalıştıklarım

- 🎢 **Kaotik Sistemler ve Sarkaç Tabanlı Şifre Üretimi:**  
  Sarkaç hareketlerinden ve lav lambası görüntülerinden veri toplayarak gerçek zamanlı olarak kaotik sistem analizi yapıyor ve benzersiz şifreler üretiyorum.  
  Kullanıcı arayüzü: Python + OpenCV + Matplotlib + QRCode + Webcam  
  Proje, akademik seminerimle doğrudan bağlantılı.

- 🖥️ **WordPress ile Web Geliştirme:**  
  WordPress altyapısı ile kullanıcı dostu web siteleri oluşturuyorum. Özelleştirme, tema geliştirme ve içerik entegrasyonu gibi konularla ilgileniyorum.

- 📊 **Moodle'da AI Tabanlı Soru Analizi:**  
  Öğrencilerin sınavlardaki hatalarını analiz edip NLP ile konuya yönlendiren bir sistem geliştiriyorum.
